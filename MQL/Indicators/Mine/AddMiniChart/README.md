# AddMiniChart

MT5チャートの左下にミニチャートを表示するインジケーター。

## 特徴

- チャート左下に上位時間足のミニチャートを表示
- 1枚 / 縦2枚 / 横2枚 のレイアウトを選択可能
- 表示する時間足をパラメータで自由に指定
- サイズ（幅・高さ）もパラメータで調整可能
- **MT5専用**（MT4では動作しない）

## ファイル構成

```
AddMiniChart/
├── AddMiniChart.mq5   ← インジケーター本体
└── MiniChart.mqh      ← ミニチャートクラス（ライブラリ）
```

## インストール

1. `AddMiniChart.mq5` と `MiniChart.mqh` を同じフォルダに配置
   ```
   MQL5/Indicators/<任意のフォルダ>/AddMiniChart/
   ```
2. MetaEditorで `AddMiniChart.mq5` を開いてコンパイル（F7）
3. MT5のナビゲーターからチャートにドラッグ＆ドロップ

## パラメータ

| パラメータ | デフォルト | 説明 |
|---|---|---|
| レイアウト | 縦2枚 | 1枚 / 縦2枚 / 横2枚 |
| チャート1 時間足 | H1 | 1枚目に表示する時間足 |
| チャート2 時間足 | H4 | 2枚目に表示する時間足（2枚表示時のみ有効） |
| 幅（ピクセル） | 300 | ミニチャートの幅 |
| 高さ（ピクセル） | 200 | ミニチャートの高さ |

## 動作環境

- MetaTrader 5
- MQL5コンパイラ
