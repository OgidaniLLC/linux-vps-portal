# AddMiniChart ユーザーマニュアル

**Version:** 1.0（2026-05-30）
**対象:** AddMiniChart.mq5（MT5用インジケーター）

---

## 1. 概要

AddMiniChart は MT5 チャートの左下にミニチャートを表示するインジケーターです。

現在見ているチャートから離れることなく、上位時間足の値動きをその場で確認できます。

### 主な特徴

- チャート左下にミニチャートを常時表示
- 1枚・縦2枚・横2枚のレイアウトを選択可能
- 表示する時間足を自由に指定（H1・H4・D1など）
- サイズ調整可能
- **MT5専用**（MT4では動作しません）

---

## 2. インストール

### 配置手順

`AddMiniChart.mq5` と `MiniChart.mqh` を **同じフォルダ** に配置してください。

```
MT5データフォルダ/MQL5/Indicators/Mine/AddMiniChart/
├── AddMiniChart.mq5
└── MiniChart.mqh
```

> データフォルダは MT5 メニューの **ファイル → データフォルダを開く** で確認できます。

### コンパイル

1. MetaEditorで `AddMiniChart.mq5` を開く
2. **F7** キーでコンパイル
3. エラーがないことを確認

### チャートへの適用

MT5のナビゲーター（Ctrl+N）から `AddMiniChart` を探し、チャートにドラッグ＆ドロップします。

---

## 3. パラメータ設定

| パラメータ | デフォルト | 説明 |
|---|---|---|
| **レイアウト** | 縦2枚 | 表示形式を選択 |
| **チャート1 時間足** | H1 | 1枚目（または1枚表示時）の時間足 |
| **チャート2 時間足** | H4 | 2枚目の時間足（2枚表示時のみ有効） |
| **幅（ピクセル）** | 300 | ミニチャートの幅 |
| **高さ（ピクセル）** | 200 | ミニチャートの高さ |

### レイアウトの選択肢

| 設定値 | 表示 |
|---|---|
| **1枚** | ミニチャート1枚のみ表示 |
| **縦2枚**（デフォルト） | 左下に縦に2枚並べて表示 |
| **横2枚** | 左下に横に2枚並べて表示 |

---

## 4. 使用例

### M15チャートでH1とH4を確認したい場合

| パラメータ | 設定値 |
|---|---|
| レイアウト | 縦2枚 |
| チャート1 時間足 | H1 |
| チャート2 時間足 | H4 |
| 幅 | 300 |
| 高さ | 200 |

### H1チャートでD1だけ確認したい場合

| パラメータ | 設定値 |
|---|---|
| レイアウト | 1枚 |
| チャート1 時間足 | D1 |
| 幅 | 400 |
| 高さ | 250 |

## 5. トラブルシューティング

### ミニチャートが表示されない

- `AddMiniChart.mq5` と `MiniChart.mqh` が**同じフォルダ**にあるか確認
- MetaEditorで再コンパイル後、チャートに再適用

### `CMiniChart Create failed` とログに出る

- MT4のチャートに適用していないか確認（MT5専用）
- チャートを一度閉じて再度適用

### サイズが大きすぎる / 小さすぎる

- **幅・高さ**パラメータを調整してください
- 縦2枚の場合、高さ×2 の領域が必要です

---

## 6. 動作仕様

- ミニチャートは `OBJ_CHART` オブジェクトとして描画されます
- 配置基準は**左下コーナー**（`CORNER_LEFT_LOWER`）
- ミニチャートのスケールは現在チャートより1段小さく自動設定されます
- 日付軸・価格軸は非表示（すっきり表示）
- インジケーター削除時にミニチャートオブジェクトも自動削除されます

---

## 7. 動作環境

- MetaTrader 5
- MT4では動作しません（`OBJ_CHART` はMT5専用機能）
