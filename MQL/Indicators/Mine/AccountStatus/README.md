# AccountStatus

MT5/MT4チャートのサブウィンドウに口座残高の推移をグラフ表示するインジケーター。

[English](README.en.md)

## 特徴

- 過去の取引履歴から残高推移・最大残高・余剰証拠金をラインで表示
- マウスオーバーでその時点の残高・最大DD・損益をポップアップ表示
- 左下の＋ボタンで凡例をトグル表示
- MT5 / MT4 両対応

## 表示ライン

| ライン | 色（デフォルト） | 説明 |
|---|---|---|
| **Balance（口座残高）** | 青（DodgerBlue） | 各時点での推定口座残高 |
| **Margin Free（余剰証拠金）** | 赤（Red） | ポジション保有中の余剰証拠金。リアルタイムのティック更新時のみ記録されるため、過去バーは空白になる場合があります |
| **Max Balance（最大残高）** | 黄（Yellow） | その時点までの過去最高残高 |

## 用語

| 用語 | 説明 |
|---|---|
| **Balance** | 口座の現金残高。保有ポジションの評価損益は含まない |
| **Margin Free** | 新規注文に使用できる資金。残高 − 使用済み証拠金 |
| **Max Balance** | 過去から現在までで残高が最も高かった値 |
| **Drawdown（DD）** | 最大残高からの下落幅。最大残高 − 現在残高 |
| **クレジット** | ブローカーから付与されるボーナス資金 |

## パラメータ

| パラメータ | デフォルト | 説明 |
|---|---|---|
| 口座残高 | ON | Balanceライン表示 |
| 余剰証拠金 | ON | Margin Freeライン表示 |
| 最大口座残高 | ON | Max Balanceライン表示 |
| 情報表示フォントサイズ | 大 | ポップアップのフォントサイズ |
| 口座残高にクレジットを加算する | ON | ボーナスを残高に含めるか |
| 表示上限（%） | 101 | 値幅に対する上限位置。101で上に1%余白 |
| 表示下限（%） | 0 | 値幅に対する下限位置。95にすると上位5%のみ表示 |

## 動作環境
