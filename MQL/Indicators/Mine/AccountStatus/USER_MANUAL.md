# AccountStatus ユーザーマニュアル

**Version:** 1.0（2026-05-31）
**対象:** AccountStatus.mq5 / AccountStatus.mq4（MT5 / MT4 対応）

---

## 1. 概要

AccountStatus はサブウィンドウに口座の残高推移をグラフ表示するインジケーターです。

過去の取引履歴から残高・余剰証拠金・最大残高を時系列で可視化し、マウスオーバーで任意の時点のドローダウンや残高を確認できます。

### 主な特徴

- **残高推移グラフ**: 過去の取引履歴から残高変化をラインで表示
- **最大残高ライン**: 過去最大残高の推移を表示
- **余剰証拠金ライン**: 余剰証拠金の推移を表示
- **マウスオーバーポップアップ**: カーソル位置の残高・最大DD・損益を表示
- **表示範囲指定**: 上限・下限を%で指定して注目したい範囲に絞り込み可能
- **凡例表示**: 左下の＋ボタンで凡例をトグル表示
- **MT5 / MT4 両対応**

---

## 2. インストール

### 配置手順

`AccountStatus.ex5`（または `.ex4`）を MT5/MT4 のデータフォルダに配置します。

**MT5:** MT5データフォルダ内の `MQL5/Indicators/` に配置してください。

**MT4:** MT4データフォルダ内の `MQL4/Indicators/` に配置してください。

> データフォルダは MT5/MT4 メニューの **ファイル → データフォルダを開く** で確認できます。

### チャートへの適用

ナビゲーター（Ctrl+N）から `AccountStatus` を探し、チャートにドラッグ＆ドロップします。サブウィンドウに表示されます。

---

## 3. 表示ライン

グラフには以下の3本のラインが表示されます。

| ライン | 色（デフォルト） | 説明 |
|---|---|---|
| **Balance（口座残高）** | 青（DodgerBlue） | 各時点での推定口座残高。取引の損益を積み上げて過去を復元しています |
| **Margin Free（余剰証拠金）** | 赤（Red） | ポジション保有中の余剰証拠金。**リアルタイムのティック更新時のみ記録**されるため、インジケーター適用前の過去バーは空白になります |
| **Max Balance（最大残高）** | 黄（Yellow） | その時点までの過去最高残高。常にBalanceライン以上の値になります |

---

## 4. 用語説明

| 用語 | 説明 |
|---|---|
| **Balance（残高）** | 口座の現金残高。保有ポジションの評価損益は含まない |
| **Margin Free（余剰証拠金）** | 新規注文に使用できる資金。残高 − 使用済み証拠金 |
| **Max Balance（最大残高）** | 過去から現在までで残高が最も高かった値 |
| **Drawdown（ドローダウン / DD）** | 最大残高からの下落幅。`最大残高 − 現在残高` で計算。ポジションの含み益により残高が過去最高を超えている場合はマイナス値になります |
| **最大DD%** | ドローダウンを最大残高に対する割合で表したもの。`DD ÷ 最大残高 × 100`。マイナスの場合は過去最高更新中を意味します |
| **クレジット** | ブローカーから付与されるボーナス資金。残高への加算はパラメータで切り替え可能 |

## 5. パラメータ設定

| パラメータ | デフォルト | 説明 |
|---|---|---|
| **口座残高** | ON | Balanceラインを表示するか（青/DodgerBlue） |
| 　┣色 | 青（DodgerBlue） | Balanceラインの色（MT4のみ変更可） |
| 　┗ラベル表示 | 金額 | グラフ右端のラベル表示形式（なし / 名称+金額 / 名称 / 金額） |
| **余剰証拠金** | ON | Margin Freeラインを表示するか（赤/Red）。リアルタイム更新時のみ記録 |
| 　┣色 | 赤（Red） | Margin Freeラインの色（MT4のみ変更可） |
| 　┗ラベル表示 | 金額 | グラフ右端のラベル表示形式 |
| **最大口座残高** | ON | Max Balanceラインを表示するか（黄/Yellow） |
| 　┣色 | 黄（Yellow） | Max Balanceラインの色（MT4のみ変更可） |
| 　┗ラベル表示 | 金額 | グラフ右端のラベル表示形式 |
| **情報表示フォントサイズ** | 大（16） | マウスオーバーポップアップのフォントサイズ（小=10 / 大=16） |
| **口座残高にクレジットを加算する** | ON | ブローカーのボーナスクレジットを残高に含めるか |
| **表示上限（%）** | 101 | 全体の値幅に対する上限位置。100を超えると上に余白ができます |
| **表示下限（%）** | 0 | 全体の値幅に対する下限位置。大きくするほど上位に絞り込まれます |

### 表示範囲の設定例

グラフの値幅（最大値 − 最小値）を100%として上下の表示範囲を指定します。

| 設定 | 上限 | 下限 | 効果 |
|---|---|---|---|
| 全範囲表示（デフォルト） | 101 | 0 | 全体＋上に1%余白 |
| 上位5%に絞る | 101 | 95 | 最大値付近のみ拡大表示 |
| 下位10%に絞る | 10 | 0 | 最小値付近のみ拡大表示 |
| 中央付近を見る | 60 | 40 | 中間の値幅を拡大表示 |

> **含み益が大きい場合**: ポジション保有中は含み益が加算されるため、グラフが一時的に大きく上振れすることがあります。上限を大きめ（105〜110）に設定すると見やすくなります。

## 6. 使い方

### 凡例の表示

サブウィンドウ左下の **＋ボタン** を押すと凡例が表示されます。もう一度押すと非表示になります。

### マウスオーバーポップアップ

グラフ上でマウスカーソルを動かすと、約0.1秒後にカーソル位置のバー情報がポップアップ表示されます。

| 項目 | 説明 |
|---|---|
| **時刻** | そのバーの時刻 |
| **最大DD** | その時点の最大残高からのドローダウン（金額・%） |
| **残高** | その時点の推定残高 |
| **最大損益** | そのバー内で記録された最大損益（含み損益の最小値） |

ポップアップはカーソルを止めてから約3秒で自動的に消えます。

> **注意**: ポップアップはサブウィンドウ内でのみ動作します。メインチャート上ではポップアップは表示されません。

---

## 7. 注意事項

- **過去残高は推定値**です。現在残高から過去の取引損益を逆算して計算しています。入出金履歴は反映されません。
- MT4ではチャートに読み込まれているバー数に依存します。バー数が少ない場合は古い履歴が最古バーに集約されます。
- **余剰証拠金（赤ライン）はリアルタイムのティック更新時のみ記録**されます。インジケーターを適用する前の過去バーには表示されません。長く表示させるにはインジケーターを継続して適用し続ける必要があります。
- **MT5ではライン色はコード固定**です（DodgerBlue / Red / Yellow）。変更する場合はソースを修正してください。
