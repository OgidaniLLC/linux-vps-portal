# MTAccountLabel ユーザーマニュアル

**Version:** 1.00（2026-07-22）
**対象:** MTAccountLabel（MT5 / MT4 インジケーター）＋ 描画用DLL（MT5用 `MTFloatingLabel.dll` / MT4用 `MTFloatingLabel32.dll`）

---

## 1. 概要

MTAccountLabel は、MT4/MT5のメインウィンドウ上に**クリック透過するフローティングラベル**を表示するインジケーターです（描画には同梱のDLLを使用します）。

複数のMTを同時に起動する環境（特にVPS / RDP）で、各ウィンドウが**どの口座か一目で識別**できるようにすることを目的としています。

### 主な特徴

- **チャート状態に依存しない表示**: タブ切替・シンボル変更・時間足変更でも表示が消えない・ズレない（表示をチャートではなくMTメインウィンドウに関連付け）
- **クリック透過**: 通常時はラベル全体がマウス入力を背後のチャート・ポジション一覧・取引履歴・ツールバーへそのまま渡す
- **Ctrlドラッグで移動**: `Ctrl` を押している間だけラベルがドラッグを受け取り、文字部分を左ドラッグで位置変更。離すと再びクリック透過へ戻る
- **座標の永続化**: ドラッグ後の座標を保存し、MT再起動後も復元（入力パラメータの `PositionX`/`PositionY` を変更した場合は保存座標を破棄して新しい値を使用）
- **MT4/MT5両対応**: 表示ロジックを共通化（DLLはMT5用64bit・MT4用32bitを個別提供）
- **MT本体に非干渉**: タイトルや内部コントロールは一切変更しない

---

## 2. 動作要件

- **MT5版**: MetaTrader 5
- **MT4版**: MetaTrader 4（build 600以降）
- **共通**: インジケーター適用時に「**DLLの使用を許可**」を有効にすること（DLLが描画を担当するため必須）

## 3. インストール

### 配布物の構成

```
MTAccountLabel/
├── USER_MANUAL.md
├── MQL5/
│   ├── Libraries/
│   │   └── MTFloatingLabel.dll                ← MT5用（64bit）
│   └── Indicators/MTAccountLabel/
│       └── MTAccountLabel.ex5
└── MQL4/
    ├── Libraries/
    │   └── MTFloatingLabel32.dll              ← MT4用（32bit）
    └── Indicators/MTAccountLabel/
        └── MTAccountLabel.ex4
```

### 配置手順

MT5/MT4のデータフォルダ（**ファイル → データフォルダを開く**）配下に、各ファイルをそのままコピーします（リネーム不要）。

#### MT5の場合

| 配布ファイル | 配置先 |
|---|---|
| `MTFloatingLabel.dll`（x64） | `MQL5/Libraries/` |
| `MTAccountLabel.ex5` | `MQL5/Indicators/MTAccountLabel/` |

#### MT4の場合

| 配布ファイル | 配置先 |
|---|---|
| `MTFloatingLabel32.dll`（x86） | `MQL4/Libraries/` |
| `MTAccountLabel.ex4` | `MQL4/Indicators/MTAccountLabel/` |

> ⚠️ DLLを差し替える場合は、MTを**完全に終了してから**実施してください（実行中はファイルロックされます）。
> MT5用は64bitの `MTFloatingLabel.dll`、MT4用は32bitの `MTFloatingLabel32.dll` です。ファイル名が異なるので、それぞれ対応する `Libraries` フォルダに配置してください。

### 起動方法

1. MTを起動し、ナビゲータ → 「インジケーター」→ 「MTAccountLabel」→ **MTAccountLabel** を任意のチャートにドラッグ
2. 表示される設定ダイアログで「**DLLの使用を許可**」にチェック
3. 入力パラメータ（後述）を設定して OK

1チャートに1つ適用すれば動作します。スレーブEA等が乗っている別チャートに重ねる必要はありません。

## 4. 入力パラメータ

| パラメータ | 入力方法 | デフォルト | 説明 |
|---|---|---|---|
| `LabelText` | 文字入力 | `Label` | 表示する文言（例: 口座名・ブローカー名・口座番号など）。1〜128文字 |
| `TextColor` | カラーピッカー | `clrWhite` | 文字の色 |
| `BackgroundColor` | カラーピッカー | `clrDarkSlateGray` | 文字の後ろに敷く背景パネルの色。**`BackgroundOpacity` が `0` のときは表示されません**（下記参照） |
| `BackgroundOpacity` | 数値（`0`〜`255`） | `0` | 背景パネルの濃さ。`0`=透明でパネルなし（文字のみ）、`255`=くっきり表示。**カラーピッカーではなく数値欄です** |
| `FontName` | 文字入力 | `Broadway` | フォント名 |
| `FontSize` | 数値 | `32` | フォントサイズ（DIP単位、8〜72） |
| `PositionX` | 数値 | `20` | MTメインウィンドウ左端からのX座標（DIP、0〜10000） |
| `PositionY` | 数値 | `40` | MTメインウィンドウ上端からのY座標（DIP、0〜10000） |

> **背景パネルについて（重要）**
> 色に関する設定は **`BackgroundColor`（色ピッカーで色を選ぶ）** と **`BackgroundOpacity`（数値で濃さを指定）** の2つに分かれています。
> - デフォルトは `BackgroundOpacity = 0`（透明）のため、`BackgroundColor` で何色を選んでも**背景は見えず、文字だけが浮かんで表示**されます。
> - 背景パネルを表示したい場合は、**`BackgroundColor` で色を選んだ上で、`BackgroundOpacity` を `128`〜`255` などに数値で上げてください。** この2つはセットで設定して初めて背景に色が付きます。

## 5. 操作方法

### 位置の移動（Ctrlドラッグ）

1. `Ctrl` キーを押し続ける
2. ラベルの**文字部分**を左ドラッグして好きな位置へ移動
3. `Ctrl` を離すと、再びクリック透過状態に戻る

- 移動後の座標は自動保存され、MT再起動後も復元されます。
- 入力パラメータの `PositionX` / `PositionY` を変更してOKすると、保存座標は破棄され、新しい入力値の位置に表示されます。

### クリック透過について

通常時（Ctrlを押していないとき）は、ラベル全体がマウス入力を透過します。ラベルの上をクリック・ドラッグしても、背後のチャート・ポジション一覧・取引履歴・ツールバーがそのまま操作できます。

## 6. トラブルシューティング

### ラベルが表示されない

1. インジケーター設定で「**DLLの使用を許可**」が有効か確認
2. DLLが正しいフォルダに配置されているか確認（MT5=`MQL5/Libraries/MTFloatingLabel.dll`、MT4=`MQL4/Libraries/MTFloatingLabel32.dll`）
3. MT4に64bit版、MT5に32bit版を誤って入れていないか確認（MT5=64bit、MT4=32bit）
4. DLL差し替え直後はMTを再起動

### ラベルがMTウィンドウからはみ出る・見えない位置にある

- 入力パラメータの `PositionX` / `PositionY` を小さい値（例: 20 / 40）に設定し直してOK。保存座標が破棄され、見える位置に戻ります。

### 文字は表示されるが背景（色付きパネル）が出ない

- 仕様です。既定値が `BackgroundOpacity = 0`（透明）のため、`BackgroundColor` で色を選んでも背景は表示されません。
- 背景を出すには、`BackgroundColor` で色を選んだ上で **`BackgroundOpacity` を数値で `128`〜`255` に上げて** ください（色ピッカーだけでは背景は付きません）。

### MT本体のタイトルやレイアウトが変わってしまった

- 本インジケーターはMT本体のタイトルや内部コントロールを一切変更しません。該当する場合は別の原因です。

---

## 7. 制限・注意事項

- 表示はオーバーレイ（owner付きレイヤードウィンドウ）で実現しており、MT本体の内部構造には手を加えません。MTのアップデートで内部ウィンドウ構造が変わった場合、安全に表示を停止する設計です。
- DLLの異常が売買処理に波及しないよう、取引API・チャートオブジェクト・EA領域は使用していません。
- 1チャートにつき1インジケーター適用を想定しています。誤って複数適用しても二重表示を防止します。
