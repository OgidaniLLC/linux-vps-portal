# AutoWinRestart

指定した曜日・時刻に **Windows を自動で再起動**する MT5 / MT4 用インジケーターです。

VPS や自宅 PC で MT を 24 時間稼働させていると、メモリ肥大化・フリーズ・Windows Update の保留などで動作が不安定になります。本ツールをチャートに 1 つ載せておくだけで、**毎週決まった曜日・時刻に PC 上のすべての MT を閉じて Windows を再起動**し、クリーンな状態を保ちます。

## ダウンロード

[**こちらからダウンロード**](https://github.com/OgidaniLLC/linux-vps-portal/releases/tag/v-latest) → `AutoWinRestart.zip`

> 解凍には [7-Zip](https://www.7-zip.org/) とパスワードが必要です。

| ファイル | 対応 |

| `AutoWinRestart.ex5` | MetaTrader 5 |

## インストール

1. MT4/MT5 を開き、メニューから **ファイル → データフォルダを開く**
2. `MQL4\Indicators\`（または `MQL5\Indicators\`）に `AutoWinRestart.ex4`／`.ex5` をコピー
3. MT4/MT5 を再起動（またはナビゲーターを更新）
4. ナビゲーター → インジケーター → `AutoWinRestart` を任意のチャートにドラッグ

> **重要:** チャートに適用する際、「DLL の使用を許可する」にチェックを入れてください。
> （ツール → オプション → エキスパートアドバイザー でも許可が必要です）

---

## 設定（パラメータ）

| パラメータ | 既定値 | 説明 |
|---|---|---|
| `Restart day of the week` | 日曜（SUNDAY） | 再起動する曜日 |
| `Restart time` | `"23:00"` | 再起動する時刻（`HH:MM`、**取引サーバー時刻**で判定） |

---

## 重要な注意

- ⏰ **時刻は「取引サーバー時刻」で判定します**（日本時間ではありません）。サーバー時刻はブローカーにより GMT+2／+3 などで、日本時間とは数時間ずれます。
- 📅 **週末（土日）に再起動したい場合は、BTCUSD など 24 時間取引の銘柄チャートに設置してください。**
  FX 銘柄は土日にレートが止まり、サーバー時刻が金曜終値で固定されるため、土日を指定しても発火しません。BTCUSD など 24 時間配信の銘柄チャートなら週末も正しく再起動します。**平日のみの再起動なら銘柄は問いません。**
- 🔁 本ツールは **Windows を再起動**します。再起動の 60 秒前に予告が出ます（`shutdown /a` で中止可）。再起動後に MT を自動起動する設定（スタートアップ等）と併用してください。
- 閉じるのは PC 上の **MT5 / MT4 のみ**です（他のアプリは閉じません）。

> 詳しい使い方・動作仕様・トラブルシューティングは、zip 同梱の `USER_MANUAL.md` を参照してください。

---

## 注意事項

- DLL の使用許可が必要です（shell32.dll / user32.dll を使用）
- 取引中のポジションがある場合、再起動中（数十秒〜数分）は MT が停止し自動売買も止まります。重要な時間帯を避けて設定してください。
