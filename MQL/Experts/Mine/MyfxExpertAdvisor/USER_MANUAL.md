# MyfxExpertAdvisor ユーザーマニュアル

**Version:** 1.06（2026-06-14）
**対象:** MyfxExpertAdvisor（MT5 / MT4 EA）

Myfxbook のアカウント情報（残高・損益・ポジション等）を MT5/MT4 のチャート上で確認できる EA です。

---

## 動作環境

| 項目 | 内容 |
|------|------|
| 対応プラットフォーム | MetaTrader 5 / MetaTrader 4 |
| 必要アカウント | [Myfxbook](https://www.myfxbook.com) アカウント |

---

## 導入手順

### 1. ファイルの配置

EX5（またはEX4）ファイルを MT のデータフォルダに配置します。

**MT5 の場合**
```
<データフォルダ>/MQL5/Experts/
```

**MT4 の場合**
```
<データフォルダ>/MQL4/Experts/
```

> データフォルダは MT5/MT4 メニューの **ファイル → データフォルダを開く** で確認できます。

---

### 2. WebRequest の許可設定

この EA は Myfxbook の API を使用するため、WebRequest の許可が必要です。

1. MT5/MT4 のメニューから **ツール → オプション** を開く
2. **Expert Advisors** タブを選択
3. **「以下のURLへの WebRequest を許可する」** にチェックを入れる
4. URLリストに以下を追加する

```
https://www.myfxbook.com
```

5. **OK** をクリック

---

### 3. チャートへの配置

1. ナビゲーターウィンドウから **MyfxExpertAdvisor** をチャートにドラッグ＆ドロップ
2. パラメータ設定ダイアログが開く
3. 下記のパラメータを設定して **OK** をクリック

---

## パラメータ設定

### Myfxbook アカウント

| パラメータ（日本語版） | パラメータ（英語版） | 説明 |
|----------------------|-------------------|------|
| **e-mail** | **e-mail** | Myfxbook に登録したメールアドレス |
| **Password** | **Password** | Myfxbook のパスワード |
| **使用または保存するアカウント** | **Account to be used or saved** | ログイン情報を保存するスロット番号（#1〜#5）。複数のアカウントを使い分ける場合に番号を変えて保存できます |
| **保存を削除するアカウント** | **Account to delete save** | 保存済みのログイン情報を削除するスロット番号 |
| **タイムアウト(ms)** | **Timeout(ms)** | API通信のタイムアウト時間（デフォルト: 5000ms）|

> **注意:** e-mail と Password は初回のみ入力が必要です。ログイン後はセッション情報が自動保存されるため、次回以降は空欄のまま使用できます。

> **「Max login attempts reached」と表示された場合:** Myfxbook のウェブサイト（https://www.myfxbook.com）から一度ログインしてください。

## 画面説明

### Total タブ

登録されている Myfxbook アカウントの一覧を表示します。

| 列 | 説明 |
|----|------|
| Name | アカウント名 |
| Gain [%] | 損益率 |
| Equity | 有効証拠金 |
| Balance | 残高 |
| Profit | 損益 |
| PF | プロフィットファクター |
| pips | 合計pips |
| Dairy [%] | 日次損益率 |
| Monthly [%] | 月次損益率 |
| Account | 口座番号 |
| Update | 最終更新日時 |

**Refresh ボタン:** クリックするとアカウント情報を再取得します。

---

### Period タブ

期間別の損益集計を表示します。

| 列 | 説明 |
|----|------|
| Name | アカウント名 |
| pips | 期間内の合計pips |
| Lots | 期間内の合計ロット数 |
| Profit | 期間内の損益 |
| Update | 最終更新日 |

**期間ボタン:**

| ボタン | 説明 |
|--------|------|
| Y | 今年の1月1日〜現在 |
| M | 今月1日〜現在 |
| W | 今週月曜日〜現在 |
| D | 今日〜現在 |

期間を選択後、**上下矢印キー**で前後の期間に移動できます。

---

### Positions タブ

選択したアカウントの現在のオープンポジションを表示します。

**Name（コンボボックス）:** 表示するアカウントを選択します。「--- All Account ---」を選択すると全アカウントのポジションをまとめて表示します。

**表示モード:**

| モード | 説明 |
|--------|------|
| Position | ポジション別に一覧表示 |
| Symbol | 通貨ペア別に集計表示 |
| Type | 売買種別（Buy/Sell）で集計表示 |

| 列 | 説明 |
|----|------|
| Time | オープン日時 |
| Symbol | 通貨ペア |
| Type | Buy / Sell |
| Lots | ロット数 |
| Price | オープン価格 |
| Swap | スワップ |
| Profit | 損益 |

## ログイン情報の保存について

- 初回ログイン後、メールアドレス・セッション・パスワードは自動保存されます
- 次回からは e-mail・Password を空欄のままでも自動的にログインします
- MT5 と MT4 は別々にセッション情報を保持します（起動順は問いません）
- 保存情報を削除するには **保存を削除するアカウント** パラメータで対象スロットを指定してリロードしてください

---

## トラブルシューティング

| 症状 | 対処法 |
|------|--------|
| 「Invalid session.」と表示される | Refresh ボタンを押すか、EA をリロードしてください |
| 「Max login attempts reached」と表示される | Myfxbook のウェブサイトから一度ログインしてください |
| 「Required fields missing.」と表示される | e-mail と Password を入力してリロードしてください |
| データが表示されない | WebRequest の許可設定を確認してください |
| Positions が表示されない | Refresh ボタンを押すか、アカウントを選び直してください |
| 一時的に更新されない | Myfxbook 側のアクセス制限（混雑時）の可能性があります。しばらくすると自動的に回復します。直前に取得済みの情報は表示し続けます |
