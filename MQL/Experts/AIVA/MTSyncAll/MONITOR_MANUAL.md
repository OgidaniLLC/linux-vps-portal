# MTS_CopyMonitor ユーザーマニュアル

**Version:** 1.01（2026-06-04）
**対象インジケーター:** MTS_CopyMonitor v1.01 (MT5)

---

## 1. 概要

MTS_CopyMonitor は MTSyncAll コピートレードEAのスレーブ側状態を可視化するモニタリング用インジケーターです。

- **マスター側で保有中のポジション一覧**をリアルタイムに表示
- **コピー成功 / スキップ / 失敗 / 未処理** の状態を一目で確認
- HB途絶やマスター/スレーブ件数の不一致を**色で警告**
- 通貨タブで絞り込み、複数スレーブ(magic)の切替対応

---

## 2. 動作要件

**MT5版 (`MTS_CopyMonitor.ex5`)**
- MetaTrader 5

**MT4版 (`MTS_CopyMonitor.ex4`)**
- MetaTrader 4 (build 600以降)

**共通**
- MTSyncAll コピートレード EA（`MTS_CopySlave.ex5` または `MTS_CopySlave.ex4`）が稼働していること
- スレーブEAには**ビルド日時から90日間の利用期限**があります。期限切れのスレーブEAは起動しないため、モニターに何も表示されなくなります。その場合は最新版のスレーブEAに差し替えてください

---

## 3. インストール

### 配布物の構成

```
MTS_CopyMonitor/
└── Indicators/MTSyncAll/
    ├── MTS_CopyMonitor.ex5   ← MT5用
    └── MTS_CopyMonitor.ex4   ← MT4用
```

### 配置手順（MT5）

MT5データフォルダ（**ファイル → データフォルダを開く**）配下にコピー。

| 配布ファイル | 配置先 |
|---|---|
| `MTS_CopyMonitor.ex5` | `MQL5/Indicators/MTSyncAll/`（例） |

### 配置手順（MT4）

MT4データフォルダ（**ファイル → データフォルダを開く**）配下にコピー。

| 配布ファイル | 配置先 |
|---|---|
| `MTS_CopyMonitor.ex4` | `MQL4/Indicators/MTSyncAll/`（例） |

---

## 4. 起動方法

**MT5の場合**
1. MT5起動
2. ナビゲータ → 「インジケーター」→ 「MTSyncAll」→ **MTS_CopyMonitor**
3. 任意のチャートにドラッグ
4. パラメータ設定(後述)→ OK

**MT4の場合**
1. MT4起動
2. ナビゲータ → 「インジケーター」→ 「MTSyncAll」→ **MTS_CopyMonitor**
3. 任意のチャートにドラッグ
4. パラメータ設定(後述)→ OK

スレーブEAが稼働している任意のチャートに重ねる必要はありません。**完全に独立した別チャート**でも動作します。

---

## 5. パラメータ仕様

| パラメータ | デフォルト | 説明 |
|---|---|---|
| 更新周期(ms) | 2000 | スナップショットファイルの読み込み間隔 |
| 行数上限 | 200 | テーブルの最大行数 |
| 表示行数 | 15 | 一度に表示する行数（スクロール可） |

- 初期選択スレーブ・タブ・ウィンドウ位置は自動設定されます
- 起動時に自動検出された先頭のmagicが選択されます
- ALLタブは常に先頭に固定されます

## 6. 画面構成

```
┌─ MTSync Copy Monitor ─────────────────────[─][×]─┐
│ HB: 正常 (2s 前)              Slave magic: [99000001 ▼]│
│ Master: 11 / Slave: 11                                │
│ ┌─[ALL][BTCUSD][EURUSD][GBPUSD]...─────────────────┐│
│ │Master#  Slave#   Symbol  Side Lot  Status Reason │
│ │60984748 946743210 BTCUSD SELL 0.01 copied        │
│ │60984791 946743275 BTCUSD BUY  0.01 copied        │
│ │ ...                                               │
│ └───────────────────────────────────────────────────┘│
└──────────────────────────────────────────────────────┘
```

### 上部ステータス
- **HB行**: マスターからのハートビート受信状態
  - 正常(緑) / 警告(オレンジ・10秒以上経過) / TIMEOUT(赤・閾値超え) / 未受信(赤)
- **件数行**: Master保有数 / Slave保有数
  - 件数が一致しない場合は赤色で警告表示

### Slave magic ドロップダウン(右上)
- 稼働中のスレーブが自動的にリストに追加されます
- 複数スレーブがある場合はここで監視対象を切り替えられます

### 通貨タブ
- **ALL** タブ + 過去にイベントが発生した通貨タブ
- スレーブEAの動作中に新しい通貨が出ると自動的にタブ追加(1度出た通貨タブは閉じない)

### ポジション一覧テーブル(7列)
| 列 | 内容 |
|---|---|
| Master# | マスター側ポジションのチケット番号 |
| Slave# | スレーブ側にコピーされたチケット番号(未コピー時は空) |
| Symbol | 銘柄 |
| Side | BUY / SELL |
| Lot | ロット数 |
| Status | copied / skipped / failed / pending |
| Reason | スキップ・失敗理由(該当時のみ) |

### スクロール操作
- マウスホイール = 1行ずつ上下スクロール
- スクロールバーのつまみドラッグでも操作可能

## 7. ステータス値（Status / Reason）

スレーブEAから受け取る各マスターポジションの処理結果。

| Status | 意味 | 詳細 |
|---|---|---|
| **copied** | 正常コピー済み | マスターのopenシグナルを受信し、スレーブ側でOrderSend成功。マスターticket↔スレーブticketのマッピングが確立している状態 |
| **skipped** | ガードレールでスキップ | open通知を受信したが、4ガードレール(鮮度×価格 / スプレッド / 価格乖離 / HBタイムアウト等)のいずれかでブロックされた状態。Reason列に詳細(例: `spread:0.0035>0.0020`) |
| **failed** | OrderSend失敗 | スレーブ側でOrderSendを試行したが、ブローカからエラー応答(retcode非0)。Reason列にretcode |
| **pending** | 未処理 | マスターHBに含まれているがスレーブで何も処理していない状態。主に **スレーブEA起動前からマスターで保有していたポジション** が該当(起動前のopen通知は流れないため、コピー対象外として表示) |

> ✅ **pending は異常ではありません**。スレーブEAを起動した時点でマスター側に既に保有中だったポジションは pending として表示され、マスター側でcloseされれば一覧から自動的に消えます。

## 8. トラブルシューティング

### Slave magic ドロップダウンに何も表示されない

- スレーブEAが**起動していない**、または**最新版でない**可能性
- スレーブEAバージョン: モニター連携機能は v1.1 以降で利用可能
- 共通フォルダに `slave_positions_*.jsonl` が生成されているか確認

### HB: 未受信 / TIMEOUT

- マスターEAが停止している、または通信(共有メモリ/TCP)が切断されている
- スレーブEAのログ(エキスパートログ)で「HB TIMEOUT」を確認

### 件数が一致しない(赤色警告)

- pending件数が含まれていれば、**マスター側で起動前から保有していたポジ**
- skipped/failedが含まれていれば、ガードレール調整 or ブローカエラーを確認
- Reason列の内容を見て対応(MTSyncAll本体マニュアル「コピーされるがSKIPされる」参照)
